# Data

This project uses publicly available data from the OECD PISA 2022 Database (https://www.oecd.org/en/publications/pisa-2022-results-volume-iii_765ee8c2-en.html)

The analysis combines:

- PISA 2022 Student Questionnaire
- PISA 2022 Creative Thinking Assessment

Raw datasets are not included in this repository due to file size and agreement with data use.

See the analysis file for information about data preparation and variable selection.
